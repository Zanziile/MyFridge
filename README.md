# FridgeApp — Умный холодильник без умного холодильника

Простое веб-приложение для управления продуктами и рецептами дома.

---

## Проблема

Каждый раз думать "что приготовить из того, что есть" — утомительно. Умный холодильник стоит дорого. Этот проект решает ту же задачу бесплатно: вы вводите что купили, приложение показывает что можно приготовить.

---

## Похожие проекты

| Проект | Суть | Чем отличается наш |
|---|---|---|
| **Supercook** (supercook.com) | Выбираешь продукты — получаешь рецепты | Рецепты чужие, нельзя создавать свои |
| **MyFridgeFood** | То же самое | Английский, чужие рецепты |
| **Grocy** | Трекер продуктов с датами годности | Сложный, перегруженный |
| **OurGroceries** | Список покупок | Нет рецептов |

**Наш плюс:** свои рецепты + история покупок + ползунок доступности + максимальная простота.

---

## Функциональность MVP

### 1. Холодильник
- Список продуктов которые сейчас есть дома
- Кнопка "+" чтобы добавить продукт (название + количество опционально)
- Кнопка убрать продукт одним кликом
- **История** — список ранее добавлявшихся продуктов, чтобы не вводить заново
- Drag & drop: перетаскивать из истории в холодильник

### 2. Мои рецепты
- Создание рецепта: название + список нужных продуктов
  - Пример: Хлеб + Колбаса = Бутерброд
- Список всех рецептов
- Значок ✅ / ⚠️ — полностью доступен или частично
- **Ползунок доступности**: показывать рецепты у которых есть X% ингредиентов (например 60%)
- Для частичных рецептов — список чего не хватает (чтобы докупить)

---

## Стек (предложение для MVP)

```
Frontend:  React + Vite + Tailwind CSS
Storage:   localStorage (без бэкенда на старте)
Хостинг:   Vercel (бесплатно, 1 клик деплой)
```

Без базы данных на MVP — всё хранится в браузере. Если нужно синхронизировать между телефоном и компьютером — добавить Firebase (тоже бесплатно).
